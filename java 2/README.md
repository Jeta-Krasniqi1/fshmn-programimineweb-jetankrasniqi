# Muzeu i sendeve

Një faqe e thjeshtë HTML për një ekspozitë virtuale.

## Përmbajtja

Faqja paraqet tre sende:

- Çelësi
- Filxhani
- Bileta

Çdo send përmban:

- fotografi
- përshkrim
- histori të fshehur

## Teknologjitë

- HTML5

muzeu-i-sendeve/
