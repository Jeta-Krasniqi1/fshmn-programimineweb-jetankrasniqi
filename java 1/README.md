# Pasaporta Digjitale e Jetës

## Çfarë realizova

Në këtë detyrë krijova një pasaportë digjitale për një personazh të sajuar, Jeta, e cila paraqitet si një studente e dalluar me interes për teknologjinë dhe krijimin e projekteve të reja.

Faqja kryesore `index.html` përmban titullin, një prezantim të personazhit, tri aftësi dhe një lidhje drejt faqes `rreth.html`.

Faqja `rreth.html` përmban një histori të shkurtër të personazhit dhe një lidhje për t'u kthyer në faqen kryesore.

## Si hapet projekti

1. Hap folderin `java 1`.
2. Hap `index.html` për të parë faqen kryesore.
3. Kliko lidhjen për të hapur `rreth.html`.
4. Nga `rreth.html`, kliko lidhjen e kthimit për t'u kthyer në `index.html`.
